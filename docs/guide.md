## 分析流程总览

本平台按 GWAS 下游分析的逻辑分为四步，每一步都内置了**真实的鲫鱼 (*Carassius auratus*) 示例数据**，打开页面即可看到结果。

| 步骤 | 页面 | 要回答的问题 | 核心方法 |
|---|---|---|---|
| 1 | 群体表型 | 各群体的性状是否不同？ | ANOVA / Welch / Kruskal–Wallis，Tukey / Dunn 多重比较 |
| 2 | 区域定位 | 显著信号落在哪段区间，附近有哪些基因？ | LocusZoom：−log₁₀P + LD r² + 基因结构 |
| 3 | 等位效应 | 先导 SNP 每多一个等位基因，表型改变多少？ | 加性线性模型、MAF、HWE 精确检验 |
| 4 | 候选表达 | 候选基因的表达在组间是否不同？ | log₂ 尺度检验、跨基因 FDR、Z-score 热图 |

> 所有页面左侧都可以切换为「上传文件」。CSV 与 TSV 会根据扩展名自动识别，单个文件不超过 100 MB。

## 1. 群体表型比较

### 数据格式

每行一个个体，至少包含一个分组列和一个数值性状列：

```text
FID,IID,Gender,Body_weight,Total_length,Body_length,Head_length,Body_height,Body_width
RCC,1,Female,166.6,200.3,180.6,49.1,74.2,42.3
WCC,2,Male,155.8,195.6,157.2,46.1,69.0,42.0
```

### 要点

- **异速校正**：体重、体高等性状与体长强相关。选择「性状 ÷ Body_length」可以比较体型而不是体格大小。
- **子集**：示例中 WR 全为雌性，WCC 以雄性为主。性别会混杂群体差异，建议按 `Gender` 分开比较。
- **异常值**：默认保留全部数据。只有能确认是测量或录入错误时才剔除，并在方法中注明。
- **多重比较**：*k* 个组共有 *k(k−1)/2* 对比较。Tukey HSD 自带校正，其他方法默认使用 BH-FDR。

## 2. LocusZoom 区域定位

### GWAS 结果文件

| 列 | 必需 | 说明 | 可识别的别名 |
|---|---|---|---|
| `SNP` | 否 | 标记 ID | rs、id、marker |
| `chr` | 是 | 染色体 / 连锁群 | chrom、chromosome、LG |
| `pos` | 是 | 物理位置 (bp) | bp、position、ps |
| `P` | 是 | 关联 P 值 | p_wald、p_lrt、pval |
| `R2` | 否 | 与先导 SNP 的 LD r² | ld、rsq |

GEMMA、GAPIT、PLINK 的输出改好列名后可以直接使用。LD 可以用 PLINK 计算：

```bash
plink --bfile data --r2 --ld-snp 34_12640349 --ld-window-kb 200 --ld-window 99999 --ld-window-r2 0
```

### 基因注释文件

需要 `chr, start, stop, name` 四列，可选 `ID`、`strand`、`comment`。提供 `strand` 时，图中会用箭头画出转录方向。

### 解读

- 紫色菱形是先导 SNP，颜色表示其他 SNP 与它的 LD 强度。
- 红色虚线是全基因组显著阈值（默认 5×10⁻⁸），灰色点线是提示性阈值（默认 1×10⁻⁵）。
- 「候选基因」表按与先导 SNP 的距离排序，并附带功能注释。距离为 0 表示 SNP 位于基因内部。

## 3. 基因型–表型关联

### 数据格式

```text
FID	Sample	Gender	Body_weight	Body_length	Genotype
WCC	bx2	M	372.8	232.1	1|0
WCC	bx25	M	332.9	224.8	0|0
```

基因型支持 `0/1`、`0|1`、`1|0`、`A/G`、`AG`。缺失值可以写成 `./.`、`NA` 或留空。

### 方法

1. **基因型标准化**：相位不同的杂合子（`0|1` 与 `1|0`）合并为 `0/1`。
2. **REF / ALT**：数字编码时 `0` 为 REF，字母编码时频率较高的等位基因为 REF。
3. **加性模型**：`表型 ~ ALT 剂量 (0/1/2) + 协变量`。β 表示每增加一个 ALT 拷贝的效应量，偏 R² 是 SNP 额外解释的方差比例。
4. **HWE**：Wigginton 精确检验。多群体混合样本会因 Wahlund 效应偏离 HWE，这本身不代表分型错误。
5. **两两比较**：基因型作为分类变量，结果同时列在表中，并画在图上。

> 杂合或纯合 ALT 只有少数个体时，统计功效很低。应以加性模型的 β 和置信区间为主，不要只看星号。

## 4. 候选基因表达

### 数据格式

```text
gene_symbol,HF1_1,HF1_3,HF2_2,WJ_1,WJ_2
POMC,28964.3,26208.3,67.2,9009.3,25471.7
```

- 第一列为基因名，其余列为样本。
- 分组从样本名推断：默认取最后一个下划线之前的部分（`HF1_3` → `HF1`），也可以改为「去掉末尾数字」。
- 「比较组」中第一个组为对照，log₂FC = 第二组 − 第一组。

### 方法

- 原始 TPM、FPKM 或标准化计数会先做 log₂(x+1) 转换。
- 两组比较用 Welch t 或 Wilcoxon，多组比较用 Welch ANOVA 或 Kruskal–Wallis；P 值在所选基因之间做 BH 校正。
- 本页只用于验证候选基因。全转录组差异分析请对原始 counts 使用 DESeq2、edgeR 或 limma-voom。

## 图形导出

- **PDF**：矢量格式，适合投稿和用 Illustrator 修改。
- **TIFF (LZW)**：多数期刊要求 300–600 DPI。
- **字体**：可选无衬线、衬线或 Times New Roman（已内置字体文件）。

## 常见问题

**上传后下拉框为空？** 检查分隔符是否和扩展名一致，以及数值列中是否混有文本（如 `NA*`）。

**图上没有显著性括号？** 可能已勾选「只标注显著」且没有 p.adj < 0.05 的比较。

**更换先导 SNP 后颜色不对？** R² 是相对文件中的先导 SNP 计算的，需要用新的先导 SNP 重新计算 LD。
